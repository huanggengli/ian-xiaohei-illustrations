# 调用示例

## 只规划

```text
Use $lucia-illustrations 先不要生图。分析这篇文章哪里需要配图，列出段落位置、核心意思、Lucía 的动作、物件、短标注与受光位置。

<正文>
```

## 正文配图

```text
Use $lucia-illustrations 为下面的中文文章生成 3 张独立正文配图。16:9、白底留白，深色半剪影人物参与核心动作，局部暖橙受光，不加包包。

<正文>
```

## 英语学习笔记

```text
Use $lucia-illustrations 为这段英语学习笔记生成一张图。先理解笔记真正想表达的区别，再设计动作隐喻。需要显示的英文逐字保留，人物不要固定为拿书站立。

<笔记>
```

## 个人思考

```text
Use $lucia-illustrations 为“先从收集的信息里选出一件今天能做的事”生成一张图。重新设计隐喻，不直接复刻信息井样板。让人物实际完成选择动作。
```

## 指定样板改编

```text
Use $lucia-illustrations 参考 assets/examples/13-system-bearing.png 的前后对比构图，把主题换成我的学习流程。保留系统分担重复任务的意思，使用以下真实内容替换标注。

<内容>
```

## 局部改图

```text
Use $lucia-illustrations 编辑这张图，只降低人物暖光亮度，让脸保持暗部；不要改动文字、构图、动作和其他物件。
```
