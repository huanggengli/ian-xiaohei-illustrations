# 构图模式与原创规则

每张选择一种主结构，用人物动作解释关系。

| 结构 | 画法 |
|---|---|
| 输入—处理—输出 | 人物操作中央工具，橙色箭头表示主流向 |
| 系统局部 | 只画 3–5 个关键部分，人物承担其中一个必要动作 |
| 前后对比 | 同一人物经历不同负担或工作方式，保持比例一致 |
| 角色状态 | 2–4 个动作小场景，每个只配一个短标注 |
| 概念隐喻 | 一个主要物件与人物相互作用，不堆叠设备 |
| 方法分层 | 用盒子、台阶、抽屉表达层级，人物搬运或搭建 |
| 地图路线 | 一条路径、少量节点，人物连接、开门或行走 |
| 小漫画分镜 | 2–4 个连续动作，保持角色与道具一致 |

## 生成隐喻

1. 将抽象概念换成动作：卡住、漏掉、变重、分拣、沉淀、发酵、开门、折叠、拆包、回流。
2. 选 1–2 个低科技物件：纸箱、抽屉、漏斗、秤、邮筒、井、梯子、线团、闸门、转盘、压机。
3. 让 Lucía 实际操作它，用侧身、手势、重心和身体间隙让半剪影动作可读。不要为了显示侧脸让她总看向天空。

## 从原样板适配真人

- 漏斗类角色改为人物操作独立漏斗；不让人体变成机器。
- 被压扁的角色改为弯身承重，与系统承重对照；保持人体完整。
- 多个操作角色可以是同一人的多个出场，五官隐于暗处、发型与比例一致。
- 人物不能挡住重要标签、箭头、输入输出，也不能大到抢走解释结构。

## 样图与原创

`../assets/examples/` 只在需要构图校准时查看，目录见 [examples-index.md](examples-index.md)。新文章从当前内容重新发明隐喻，不默认重复传送带断点、素材鱼、信息井、压机、发酵瓶、信任桥等旧构图。

用户明确要求“照这张／复刻／换人物”时，可沿用该样板的结构、文字和信息流，必要的真人动作适配应说明。样图中的数字、价格、评价都是示意，不能当作用户真实业绩或证言。
